Using the Archive

The Lore Archive collects recurring terms, traditions, locations, systems, and details from Avelis in one searchable reference area.

Archive Guide

Use the search field to look for a specific word, place, custom, system, character term, or other topic.

Category buttons narrow the archive to one area of Avelis worldbuilding. Select All Categories to return to the complete archive.

The Details and Cultural Notes columns provide additional context for how each entry functions within the world of Avelis.

Archive information is stored separately from this webpage in a CSV file so new entries can be added without expanding the HTML document.
